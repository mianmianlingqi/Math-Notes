# 江苏专转本 · 高等数学背诵速记

> 依据江苏省普通高校专转本选拔考试《高等数学》大纲整理  
> 定位：**考前速记**，按「口诀 → 公式 → 步骤 → 易混」排列，不含例题详解。

## 考试概况

| 项目 | 内容 |
|---|---|
| 满分 | 150 分，120 分钟 |
| 结构 | 微积分约 **80%**，线性代数约 **20%** |
| 题型 | 选择、填空、计算、证明、综合应用 |
| 难度 | 较易 30% / 中等 50% / 较难 20% |

## 怎么用

1. **第一遍**：按模块通读，标记不会的块
2. **第二遍**：遮住答案，默写「公式墙」和「口诀」
3. **第三遍**：只看「易混对比」和「大题步骤」
