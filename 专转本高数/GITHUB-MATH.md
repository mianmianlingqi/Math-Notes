# GitHub 公式渲染说明

## 行内公式（可以）

正文、列表中用 **一对美元符号** 包裹：

```markdown
设 $f(x)$ 在 $x_0$ 连续，则 $\lim_{x\to x_0} f(x)=f(x_0)$。
```

## 块级公式

独立成行，前后空行：

```markdown
$$
\lim_{x\to 0}\frac{\sin x}{x}=1
$$
```

## 表格内公式（注意）

| 规则 | 说明 |
|---|---|
| 用 `$...$` | 表格里**不要**用 `$$...$$`（块级，不渲染） |
| 绝对值 | 写 `$\vert f(x)\vert$`，不要写 `$|f(x)|$`（`|` 会被当成列分隔符） |
| 同格成对 | 每个单元格内的 `$` 必须成对，不要跨列匹配 |
| 复杂式子 | 可改用 `\displaystyle`：${\displaystyle \frac{1}{x}}$ |

## 反例

```markdown
| 例子 | sinx/x 在 x=0 |          ← 纯文本，不渲染
| 例子 | $\frac{\sin x}{x}$ 在 $x=0$ |   ← 行内，可渲染
| 公式 | $$ \frac{1}{x} $$ |      ← 表格内块级，常失败
```

## 本仓库约定

1. **表格、列表**：优先 `$...$` 行内
2. **公式墙、定理**：独立 `$$...$$` 块
3. **填空卷**：尽量纯文字，避免 `$` 干扰
